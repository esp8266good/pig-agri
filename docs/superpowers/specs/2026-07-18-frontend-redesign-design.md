# 前端整體改版設計（2026-07-18）

## 目標與範圍

整體優化 `static/index.html` 的配色、版面與互動直覺性，並新增多畫面 grid 監看模式。
採**漸進式重構**：既有 JS 核心邏輯（HLS/PDT 時間同步、bbox overlay、transport 拉桿、
VOD 回放）**原樣搬移、零行為變更**；版面、CSS、檔案結構全面重整。

需求釐清結論：

- 使用裝置：桌機與手機並重（響應式，斷點 1200px）。
- 痛點：資訊要捲動才看得到、設定頁難懂、時間軸操作不直覺、視覺質感、缺多畫面監看。
- Grid 範圍：純監看（live＋基本狀態），點格切回單畫面看詳情。
- 風格：深色精緻化（不換風格、不做雙主題）。
- 形態：拆成 css/js 檔，ES modules，零 build step，後端不動。
- 不採用：前端框架重寫（HLS 同步邏輯回歸風險高）、純 CSS 打磨（解決不了版面痛點）。

## 1. 版面架構

**桌機（≥ 1200px）雙欄：**

```text
┌────────────────────────────────────────────────────────────┐
│ Header： Logo｜攝影機選單｜RGB/Thermal｜Grid切換｜🔔｜⚙｜儲存燈 │
├────────────────────────────────────┬───────────────────────┤
│  影片畫面（bbox overlay）            │  [豬隻狀態][通知][書籤]  │
│  transport 播放控制列                │  資料面板               │
├────────────────────────────────────┤  （固定可見、獨立捲動）    │
│  時間軸：日期按鈕 + 24小時格          │                       │
└────────────────────────────────────┴───────────────────────┘
```

- 左欄：影片＋時間軸（操作流：選日期 → 點小時 → 拉進度）；右欄：豬隻狀態／通知／書籤
  三分頁。兩欄各自捲動，影片與數據同屏可見。
- 控制項全收進 header 一列；通知鈴鐺改 SVG 圖示。
- **設定自分頁移除**，改為 header 齒輪開啟的 drawer（低頻操作不佔常駐版面）。

**手機（< 1200px）單欄：** 影片 → 時間軸 → 分頁面板；分頁列 sticky 吸附面板頂端；
觸控目標（小時格、月曆日期格）至少 44px。

## 2. Grid 監看模式

- 進入：header「單畫面 ⇄ 多畫面」切換鈕（田字圖示）。Grid 取代左欄單畫面＋時間軸
  （手機為直向或 2 欄排列）。
- 每格：該攝影機 live RGB HLS 串流（靜音、無 bbox、無回放）＋資訊列（名稱、豬隻數、
  LIVE 綠點／斷線灰色「無訊號」佔位）。該欄有未讀活動量/體溫異常告警時：紅框＋警示角標。
- 互動：點格 → 切回單畫面並選中該攝影機。
- 佈局：CSS grid 依攝影機數自適應（1×2、2×2、2×3…）。
- 效能：離開 grid 銷毀所有播放器；斷線攝影機不建播放器只顯示佔位卡；豬隻數/告警
  沿用既有 WebSocket/API，不另開連線。
- 狀態記憶：模式與選中攝影機記 `localStorage`，重整後還原。

## 3. 設定面板重整

- 入口：header 齒輪 → 右側滑出 drawer（手機全螢幕）。點遮罩或 ✕ 關閉；有未儲存
  變更時關閉前提示。
- 五分組（各有標題＋一行說明）：
  1. **異常分析**：分析間隔、評估視窗、體溫偵測開關、異常閾值 σ。
  2. **錄影排程**：夜間不錄影開關、起訖時間（說明：停錄時段仍可看直播）。
  3. **儲存空間**：保留天數、最低可用空間、監控間隔。
  4. **推播通知**：ntfy 開關、URL、串流重建優先級。
  5. **進階**（預設收合）：夜間停 GPU 開關、起訖時間。
- 連動顯示：總開關關閉時附屬欄位變暗停用。
- 儲存：維持整批「儲存設定」（後端 API 不變）；成功/失敗狀態明確；欄位驗證錯誤
  （如 σ < 1.0）即時標紅在欄位旁。
- 不動 `routers/settings.py` 與 `ALLOWED_KEYS`。

## 4. 時間軸與回放互動

- **日期選擇**：常駐月曆改為日期按鈕（月曆 SVG 圖示＋「2026/07/18 ▾」）＋popover
  月曆（保留錄影綠點標記），選完自動收合。
- **24 小時格**：加高（40px，手機 44px）、格內顯示小時數字（00–23）；狀態分層：
  無錄影（暗、不可點）／有錄影（可點）／播放中（主色實心＋播放符號）／保留🔒／書籤★；
  標記維持可點 popover（編輯/取消）行為。
- **多選模式**：移除「選取」checkbox；改長按（桌機 shift+點擊）進入多選，底部滑出
  操作列（保留／書籤／刪除／取消＋已選數量）。刪除維持確認對話框。
- **VOD 辨識**：回放時影片卡頂部顯示琥珀色橫幅「回放中：{日期時段}［回到直播］」。
- transport 拉桿、PDT 對齊、hls.js 邏輯完全不動，只調外觀尺寸。

## 5. 視覺系統

- **配色**：深色基調微調為帶冷綠底蘊的深色階；背景/卡片/浮層三層分明；邊框與分隔線
  統一半透明白 token。語意色系統化：live 綠／VOD 琥珀／異常紅／thermal 橘／資訊藍
  （斷線、中性提示），每色配 dim 背景與邊框 token；消滅寫死色碼（如 `storage-pill`
  的 `#2ecc71`）；修掉 `.slot-action-menu` 引用未定義 `--surface-1` 的 bug。
- **圖示**：inline SVG sprite、stroke 風格統一（鈴鐺、齒輪、田字、月曆、播放/暫停、
  鎖、星、垃圾桶），淘汰 emoji。
- **字體**：DM Sans＋`Noto Sans TC` fallback；數字（時間碼、豬隻 ID、數據）全面
  `tabular-nums`。
- **微互動**：hover/active 回饋統一沿用 transition token；分頁與 drawer 輕量過場；
  尊重 `prefers-reduced-motion`。
- **豬隻狀態表**：異常列改左側紅粗邊＋數值紅字（不再整列紅底）；活動量加迷你橫條
  視覺化相對高低。

## 6. 檔案結構與遷移

```text
static/
  index.html          結構標記（~400 行）
  css/app.css         全部樣式
  js/api.js           fetch/WS 封裝
  js/player.js        HLS 播放、bbox overlay、transport（原邏輯原樣搬入）
  js/timeline.js      月曆、24小時格、儲存管理
  js/grid.js          新：grid 監看模式
  js/panels.js        狀態表、通知、書籤、設定 drawer
  js/main.js          初始化與模組串接
```

- `<script type="module">` 串接；零 build step；`main.py` 的 static 掛載不動。
- 遷移原則:既有函式逐段原樣搬移（只改必要的 DOM 選擇器），每個模組 `node --check`
  驗語法。
- CLAUDE.md「前端 inline script 語法檢查」慣例隨拆檔作廢，完工時更新該備註。

## 7. 驗證

- 後端測試：全套 `uv run pytest -p no:cacheprovider` 維持 0 失敗（本案不碰後端）。
- 前端實機驗證清單：live 播放、bbox 對齊、VOD 回放與 PDT 對齊、時間軸選日/選時/
  多選/保留/書籤/刪除、grid 切換與點格返回、設定儲存與連動停用、通知已讀流程、
  手機寬度 RWD（≤ 480px、< 1200px）、`prefers-reduced-motion`。

## 錯誤處理原則

- Grid 中單格 HLS 失敗：該格顯示錯誤佔位與重試鈕，不影響其他格。
- 設定儲存失敗：drawer 保持開啟、保留使用者輸入、顯示錯誤訊息。
- 既有的 WS 重連 toast、storage 狀態燈行為不變。
